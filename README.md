# 🎮 Finance RPG

A gamified financial education platform built using React and Node.js.

## 🚀 Features
- 🎮 Character system
- 💰 Budget simulation
- 💳 Debt & interest system
- 🏆 Achievements
- 📊 Net worth dashboard
- 📈 XP & Level progression

## 🛠 Tech Stack
- Frontend: React
- Backend: Node.js + Express

- Login system
